操作系统 ​

目标不是研究内核，而是理解服务为什么会卡、为什么会崩、为什么部署后和本地表现不一样。

你需要掌握什么 ​

1. 进程、线程、协程 ​

  • 进程和线程的区别
  • 用户态和内核态的基本概念
  • 多进程、多线程各自适合什么场景
  • 协程解决了什么问题，和线程的差异是什么
  • Node.js 单线程事件循环为什么也能处理高并发 IO

你至少要能回答：

  • 一个服务启动后，操作系统是如何管理它的
  • 为什么会出现僵尸进程、孤儿进程
  • 为什么 CPU 打满不一定是“请求多”，也可能是死循环或频繁上下文切换

2. 内存管理 ​

  • 虚拟内存的基本概念
  • 栈、堆分别是什么
  • 内存分配和回收的大致过程
  • 内存泄漏、内存溢出、频繁 GC 的区别
  • 页面缓存、进程内存、磁盘空间不是一回事

你至少要能处理：

  • 服务为什么越跑越占内存
  • 容器或服务器为什么会 OOM
  • 为什么机器还有空闲内存，但程序还是报错

3. 文件系统 ​

  • 文件、目录、路径、挂载的概念
  • 绝对路径和相对路径
  • 文件描述符是什么
  • 标准输入、标准输出、标准错误
  • 日志文件为什么会不断增长，如何切分和清理

你至少要理解：

  • 为什么上传、缓存、日志、数据库最终都会落到文件系统
  • 为什么磁盘满了会导致服务异常

4. IO 与网络基础 ​

  • 同步 IO、异步 IO、阻塞、非阻塞
  • 网络请求从发起到响应的大致过程
  • TCP 的连接、断开、重传、拥塞基本概念
  • 常见网络问题：超时、连接拒绝、DNS 解析失败、端口占用

你至少要会排查：

  • 服务启动了但访问不到
  • 本地能调通，线上超时
  • 接口偶发慢、文件上传慢、数据库连接慢

5. 并发与锁 ​

  • 竞争条件是什么
  • 临界区是什么
  • 互斥锁、读写锁、信号量了解其作用即可
  • 死锁出现的原因

这部分对你做这些事情很重要：

  • 处理定时任务重复执行
  • 避免多个请求同时修改同一份数据
  • 理解数据库事务和锁为什么会阻塞

6. 权限与隔离 ​

  • 用户、用户组、权限位
  • 进程以谁的身份运行
  • 为什么同一个命令不同用户执行结果不同
  • 环境变量是怎么影响程序运行的
  • 容器、虚拟机、宿主机的基本隔离关系

7. 启动、运行、退出 ​

  • 一个程序从启动到退出经历了什么
  • 前台进程、后台进程
  • 守护进程的概念
  • 信号机制，如 SIGTERM、SIGKILL
  • 服务优雅退出为什么重要

对个人开发者最实用的落地方向 ​

第一阶段 ​

  • 看懂进程、线程、内存、文件系统的基本概念
  • 能用系统命令观察 CPU、内存、磁盘、网络状态
  • 能理解常见报错背后的系统原因

第二阶段 ​

  • 把 Node.js、数据库、Nginx、Docker 的运行过程和操作系统概念对应起来
  • 学会根据现象判断是代码问题、系统问题还是环境问题

第三阶段 ​

  • 能独立定位线上慢请求、内存泄漏、端口冲突、磁盘打满、进程异常退出等问题

判断自己是否掌握 ​

  • 能解释“服务为什么会挂”
  • 能解释“为什么会慢”
  • 能解释“为什么本地正常、线上异常”
  • 能把问题定位到 CPU、内存、磁盘、网络、权限、配置中的某一类
