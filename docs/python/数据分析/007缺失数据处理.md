# 缺失数据处理

## 学习目标

- 知道缺失值的表现形式和来源
- 掌握检测、删除和填充缺失值的方法
- 理解缺失值处理对分析结果的影响

## 1. 什么是缺失值

课件里强调：缺失值是数据分析中的常见情况，不是异常情况。

在 `Pandas` 中，常见缺失值表示方式是 `NaN`。

```python
import numpy as np
import pandas as pd

print(np.nan == np.nan)    # False
print(pd.isna(np.nan))     # True
print(pd.notna(np.nan))    # False
```

## 2. 缺失值从哪里来

常见来源：

- 原始数据本来就没填
- 采集、清洗、合并过程中丢失
- 不同来源的数据字段标准不一致

## 3. 检测缺失值

```python
import pandas as pd

df = pd.DataFrame(
    {
        "name": ["Ada", "Bob", "Cindy"],
        "age": [18, None, 20],
        "score": [95, 88, None],
    }
)

print(df.isna())
print(df.isna().sum())
print(df.isna().mean() * 100)
```

常见检查思路：

- 哪些列有缺失
- 每列缺失多少个
- 缺失占比是多少

## 4. 删除缺失值

```python
import pandas as pd

df = pd.DataFrame(
    {
        "name": ["Ada", "Bob", "Cindy"],
        "age": [18, None, 20],
        "score": [95, 88, None],
    }
)

print(df.dropna())
print(df.dropna(subset=["age"]))
print(df.dropna(axis=1))
```

删除适合缺失比例较低，且删除后不会明显破坏样本结构的情况。

## 5. 填充缺失值

### 5.1 常量填充

```python
df["score"] = df["score"].fillna(0)
```

### 5.2 统计量填充

```python
df["age"] = df["age"].fillna(df["age"].mean())
```

### 5.3 前向或后向填充

适合时间序列：

```python
df["age"] = df["age"].ffill()
df["age"] = df["age"].bfill()
```

## 6. 选择删除还是填充

可以先问三个问题：

1. 缺失比例高不高
2. 这一列重不重要
3. 数据是否有时间顺序或分组结构

例如：

- 用户年龄缺失少量时，可用均值或中位数填充
- 商品 ID 缺失时，往往不能随便填，可能要直接删掉
- 时间序列缺失时，常考虑前向填充

## 7. 小结

- 先检测，再决定处理方式
- 删除简单，但可能损失样本
- 填充方便，但可能引入偏差
- 缺失值处理没有统一答案，要结合业务含义判断
