# 数据分组

## 学习目标

- 掌握 `groupby` 的基本思想
- 会做聚合、转换和过滤
- 能对分组结果应用自定义函数

## 1. `groupby` 的思路

分组分析可以理解成三步：

1. 按条件拆组
2. 对每组计算
3. 合并结果

```python
import pandas as pd

tips = pd.DataFrame(
    {
        "sex": ["Female", "Female", "Male", "Male"],
        "time": ["Lunch", "Dinner", "Lunch", "Dinner"],
        "total_bill": [12.5, 35.6, 18.0, 40.2],
        "tip": [2.5, 5.0, 3.0, 6.5],
    }
)

print(tips.groupby("sex")["tip"].mean())
```

## 2. 聚合计算

### 2.1 单个聚合函数

```python
print(tips.groupby("time")["total_bill"].mean())
print(tips.groupby("time")["total_bill"].sum())
```

### 2.2 多个聚合函数

```python
print(tips.groupby("time")["total_bill"].agg(["mean", "max", "min"]))
```

### 2.3 不同列使用不同函数

```python
print(
    tips.groupby("time").agg(
        {"total_bill": ["mean", "max"], "tip": "mean"}
    )
)
```

## 3. `transform`

`transform()` 适合“分组计算后，再把结果回填到原表”。

```python
tips["group_mean_tip"] = tips.groupby("sex")["tip"].transform("mean")
print(tips)
```

课件中还把它用于：

- 计算分组内 `z-score`
- 按组填充缺失值

## 4. 过滤分组

```python
grouped = tips.groupby("time")
result = grouped.filter(lambda x: len(x) >= 2)
print(result)
```

适合“只保留满足条件的组”。

## 5. 多字段分组

```python
print(
    tips.groupby(["sex", "time"])["tip"].mean().reset_index()
)
```

多字段分组可以从多个角度观察同一份数据。

## 6. 遍历分组

```python
for name, group in tips.groupby("sex"):
    print(name)
    print(group)
```

这对调试复杂分组逻辑很有用。

## 7. 小结

- `groupby` 是数据分析最核心的能力之一
- `agg()` 适合输出汇总结果
- `transform()` 适合回写到原表
- `filter()` 适合按组筛选
