## 阅读建议

- 文档中的代码示例尽量使用小型样例数据，便于直接复制运行。
- `Pandas` 章节建议边看边在 `Jupyter Notebook` 里尝试。
- 分组、透视表、时间序列三个专题最好配合同一份练习数据反复训练。
- 可视化部分先掌握默认用法，再逐步调整标题、颜色、坐标轴和图例。
- 目录中补充了同编号 `.py` 示例文件，可以直接运行验证文档里的关键操作。
