# 数据透视表

## 学习目标

- 知道什么是透视表
- 掌握 `pivot_table()` 的常见参数
- 理解透视表和 `groupby` 的关系

## 1. 什么是透视表

透视表本质上是对数据做“按行分组、按列展开、再聚合”。

如果你用过 Excel 的透视表，会很容易理解 `Pandas` 里的 `pivot_table()`。

## 2. 基本用法

```python
import pandas as pd

sales = pd.DataFrame(
    {
        "region": ["华东", "华东", "华北", "华北"],
        "channel": ["线上", "线下", "线上", "线下"],
        "amount": [120, 90, 150, 80],
    }
)

table = pd.pivot_table(
    sales,
    index="region",
    columns="channel",
    values="amount",
    aggfunc="sum",
)

print(table)
```

## 3. 常见参数

- `index`：行分组字段
- `columns`：列分组字段
- `values`：被统计的值
- `aggfunc`：聚合函数

多个聚合函数也可以一起用：

```python
table = pd.pivot_table(
    sales,
    index="region",
    values="amount",
    aggfunc=["sum", "mean", "count"],
)
print(table)
```

## 4. 透视表和 `groupby`

下面两种写法经常能得到相似结果：

```python
print(sales.groupby(["region", "channel"])["amount"].sum())
print(pd.pivot_table(sales, index="region", columns="channel", values="amount", aggfunc="sum"))
```

区别在于：

- `groupby` 更灵活，适合链式处理
- `pivot_table` 更接近报表视角，结果更直观

## 5. 典型场景

课件中的业务案例集中在会员数据分析，本质都属于下面几类：

- 各地区会员数量对比
- 线上和线下渠道对比
- 不同等级会员分布
- 某个指标在不同月份或不同门店的交叉汇总

## 6. 小结

- 想做报表式汇总时，优先考虑 `pivot_table`
- 行、列、值、聚合函数是四个关键参数
- 透视表和 `groupby` 经常可以互相替代
