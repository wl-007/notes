# 数据组合

## 学习目标

- 熟练使用 `concat` 连接数据
- 理解 `merge` 和 `join` 的适用场景
- 能处理按行拼接和按键合并两类问题

## 1. 为什么要组合数据

真实业务里，数据往往分散在多张表中：

- 不同年份的数据分成多个文件
- 维度表和事实表需要按主键关联
- 一部分字段在左表，另一部分字段在右表

因此组合数据是清洗阶段的常见任务。

## 2. `concat` 按行连接

```python
import pandas as pd

df1 = pd.DataFrame({"name": ["Ada", "Bob"], "score": [95, 88]})
df2 = pd.DataFrame({"name": ["Cindy"], "score": [91]})

result = pd.concat([df1, df2], axis=0, ignore_index=True)
print(result)
```

特点：

- `axis=0` 表示按行拼接
- `ignore_index=True` 可以重置索引

## 3. `concat` 按列连接

```python
import pandas as pd

left = pd.DataFrame({"name": ["Ada", "Bob"]})
right = pd.DataFrame({"city": ["上海", "北京"]})

result = pd.concat([left, right], axis=1)
print(result)
```

按列拼接时，索引会自动对齐。

## 4. 追加一行或一列

```python
import pandas as pd

df = pd.DataFrame({"name": ["Ada", "Bob"], "score": [95, 88]})
df["level"] = ["A", "B"]
```

如果只是补充一列，直接赋值通常比先构造一个新表再拼接更直接。

## 5. `merge` 按键合并

```python
import pandas as pd

orders = pd.DataFrame(
    {
        "user_id": [1, 2, 1],
        "amount": [100, 200, 150],
    }
)

users = pd.DataFrame(
    {
        "user_id": [1, 2],
        "name": ["Ada", "Bob"],
    }
)

result = pd.merge(orders, users, on="user_id", how="left")
print(result)
```

常见连接方式：

- `left`
- `right`
- `inner`
- `outer`

## 6. `join` 按索引合并

```python
import pandas as pd

left = pd.DataFrame({"score": [95, 88]}, index=["Ada", "Bob"])
right = pd.DataFrame({"city": ["上海", "北京"]}, index=["Ada", "Bob"])

result = left.join(right)
print(result)
```

如果两个 `DataFrame` 的索引已经处理好，`join()` 会比较顺手。

## 7. 什么时候用哪一个

- 只想把多个表上下堆起来，用 `concat`
- 有明确主键列，要做数据库式关联，用 `merge`
- 主要依据索引来合并，用 `join`

## 8. 小结

- 数据组合主要有两类：拼接和关联
- 先想清楚“按行、按列，还是按键”
- 合并前最好先检查键值是否重复、索引是否正确
