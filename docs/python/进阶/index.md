# Python 进阶

## 课程说明

这部分内容根据 `day01` 到 `day09` 的课堂笔记整理而成，目标不是逐字搬运原笔记，而是整理成更适合 VitePress 阅读的结构化文档。

本阶段重点围绕以下主题展开：

- 面向对象编程
- 项目拆分与学生管理系统
- 深拷贝与浅拷贝
- 闭包与装饰器
- 网络编程
- 多进程与多线程
- 上下文管理器
- 生成器与 `property`
- 正则表达式
- 数据结构与算法入门

## 学习路线

建议按下面顺序阅读：

1. [面向对象](./面向对象.md)
2. [学生管理系统与拷贝](./学生管理系统与拷贝.md)
3. [闭包与装饰器](./闭包与装饰器.md)
4. [网络编程与并发](./网络编程与并发.md)
5. [生成器与正则](./生成器与正则.md)
6. [数据结构与算法](./数据结构与算法.md)

- 面向对象、装饰器、并发这几部分建议自己手敲一遍。
- 数据结构与算法部分重点理解思路，不要只记代码。
