# 闭包与装饰器

## 学习目标

- 理解函数名也是对象
- 掌握闭包的定义和作用
- 会使用 `nonlocal`
- 理解装饰器本质
- 会写通用装饰器和带参数装饰器

## 1. 函数名也是对象

在 Python 中，函数名本身就可以当作对象使用。

```python
def hello():
    print("hello")


print(hello)
f = hello
f()
```

因此函数名可以：

- 赋值给变量
- 作为参数传递
- 作为返回值返回

## 2. 回调函数

一个函数接收另一个函数作为参数，并在内部调用它，这种写法常称为回调。

```python
def work(fn):
    fn()


def coding():
    print("正在敲代码")


work(coding)
```

## 3. 闭包

### 3.1 闭包的概念

闭包本质上是“内部函数引用了外部函数变量，并且外部函数返回了内部函数”。

闭包通常满足三个条件：

- 有函数嵌套
- 内部函数引用外部函数变量
- 外部函数返回内部函数

```python
def outer(num1):
    def inner(num2):
        print(num1 + num2)

    return inner


fn = outer(10)
fn(5)
fn(8)
```

### 3.2 闭包的作用

闭包常见作用是“保存状态”。

```python
def counter():
    count = 0

    def inner():
        nonlocal count
        count += 1
        print("当前计数：", count)

    return inner


fn = counter()
fn()
fn()
fn()
```

每次调用 `fn()`，都会继续使用上一次保存的 `count`。

## 4. `nonlocal`

如果内部函数想修改外部函数中的局部变量，需要使用 `nonlocal`。

```python
def outer():
    a = 100

    def inner():
        nonlocal a
        a += 1
        print(a)

    return inner
```

对比：

- `global`：修改全局变量
- `nonlocal`：修改外层函数变量

## 5. 装饰器的本质

装饰器本质上就是一种特殊写法的闭包，用来在不修改原函数源码的前提下，给函数增加功能。

```python
def decorator(fn):
    def inner():
        print("执行前准备")
        fn()
        print("执行后收尾")

    return inner


@decorator
def comment():
    print("发表评论")


comment()
```

上面的语法糖等价于：

```python
comment = decorator(comment)
comment()
```

## 6. 通用装饰器

如果原函数有参数或返回值，装饰器最好使用 `*args` 和 `**kwargs`。

```python
def log_decorator(fn):
    def inner(*args, **kwargs):
        print("开始执行：", fn.__name__)
        result = fn(*args, **kwargs)
        print("执行结束：", fn.__name__)
        return result

    return inner


@log_decorator
def add(a, b):
    return a + b


print(add(10, 20))
```

## 7. 多个装饰器

一个函数可以被多个装饰器修饰。

```python
def check_login(fn):
    def inner(*args, **kwargs):
        print("先验证登录")
        return fn(*args, **kwargs)

    return inner


def check_code(fn):
    def inner(*args, **kwargs):
        print("再验证验证码")
        return fn(*args, **kwargs)

    return inner


@check_login
@check_code
def publish():
    print("发布成功")


publish()
```

执行顺序要点：

- 离函数最近的装饰器先包裹
- 调用时最外层装饰器先执行

## 8. 带参数的装饰器

有时装饰器本身也需要参数，这时要多包一层函数。

```python
def log(symbol):
    def decorator(fn):
        def inner(*args, **kwargs):
            print(f"[{symbol}] 开始执行 {fn.__name__}")
            result = fn(*args, **kwargs)
            print(f"[{symbol}] 执行结束 {fn.__name__}")
            return result

        return inner

    return decorator


@log("+")
def add(a, b):
    return a + b


@log("-")
def sub(a, b):
    return a - b
```

## 9. 使用装饰器时的注意点

- 装饰器会改变函数的调用流程
- 通用装饰器尽量写成 `*args, **kwargs`
- 原函数有返回值时，装饰器别忘了 `return`
- 装饰器适合做日志、权限、耗时统计、缓存等横切逻辑

## 10. 小结

- 函数名本身就是对象
- 闭包可以保存状态
- `nonlocal` 用于修改外层局部变量
- 装饰器本质是闭包
- 语法糖 `@装饰器名` 只是更方便的写法
- 通用装饰器最好兼容参数和返回值
