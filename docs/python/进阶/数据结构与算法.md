# 数据结构与算法

## 学习目标

- 理解什么是数据结构和算法
- 掌握时间复杂度与空间复杂度
- 理解顺序表和链表
- 了解常见排序算法和二分查找
- 对树和二叉树建立基础认知

## 1. 数据结构与算法简介

一句常见总结：

`程序 = 数据结构 + 算法`

其中：

- 数据结构：数据如何存储和组织
- 算法：解决问题的思路和步骤

## 2. 算法的五个特性

- 有输入
- 有输出
- 有穷性
- 确定性
- 可行性

## 3. 时间复杂度

时间复杂度描述的是：当问题规模变大时，算法执行成本的主要变化趋势。

常用大 O 表示法：

- `O(1)`
- `O(log n)`
- `O(n)`
- `O(n log n)`
- `O(n^2)`
- `O(n^3)`

一般认为效率从高到低大致为：

`O(1) > O(log n) > O(n) > O(n log n) > O(n^2) > O(n^3)`

### 3.1 常见例子

```python
# O(1)
a = 100
b = 200
c = a + b
```

```python
# O(n)
for i in range(n):
    print(i)
```

```python
# O(n^2)
for i in range(n):
    for j in range(n):
        print(i, j)
```

### 3.2 最优和最坏复杂度

- 最优时间复杂度：最理想情况
- 最坏时间复杂度：最差情况

默认分析算法时，通常看最坏时间复杂度。

## 4. 空间复杂度

空间复杂度表示算法运行过程中临时占用内存的情况。

本质上是在讨论：

- 是更省时间
- 还是更省空间

这就是常说的“时空换取”。

## 5. 线性结构与非线性结构

### 5.1 线性结构

每个节点通常最多只有一个前驱和一个后继。

常见代表：

- 顺序表
- 链表
- 栈
- 队列

### 5.2 非线性结构

一个节点可能连接多个节点。

常见代表：

- 树
- 图

## 6. 顺序表与链表

### 6.1 顺序表

顺序表底层依赖连续存储空间。

特点：

- 支持快速按下标访问
- 尾部添加删除快
- 中间插入删除通常较慢
- 扩容可能需要搬迁

### 6.2 链表

链表不要求连续内存，而是通过节点地址关联。

特点：

- 插入删除灵活
- 不依赖连续空间
- 不支持直接按下标随机访问

## 7. 单向链表示例

```python
class SingleNode:
    def __init__(self, item):
        self.item = item
        self.next = None


class SingleLinkedList:
    def __init__(self):
        self.head = None

    def is_empty(self):
        return self.head is None

    def append(self, item):
        new_node = SingleNode(item)
        if self.head is None:
            self.head = new_node
            return

        cur = self.head
        while cur.next is not None:
            cur = cur.next
        cur.next = new_node

    def travel(self):
        cur = self.head
        while cur is not None:
            print(cur.item)
            cur = cur.next
```

常见操作：

- 判空
- 求长度
- 遍历
- 头插
- 尾插
- 指定位置插入
- 删除节点
- 查找节点

## 8. 排序算法

## 8.1 冒泡排序

核心思想：相邻元素两两比较，大的往后“冒”。

```python
def bubble_sort(nums):
    n = len(nums)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]
    return nums
```

特点：

- 思路简单
- 稳定排序
- 时间复杂度通常为 `O(n^2)`

## 8.2 选择排序

核心思想：每轮选出最小值，放到前面。

```python
def select_sort(nums):
    n = len(nums)
    for i in range(n - 1):
        min_index = i
        for j in range(i + 1, n):
            if nums[j] < nums[min_index]:
                min_index = j
        nums[i], nums[min_index] = nums[min_index], nums[i]
    return nums
```

## 8.3 插入排序

核心思想：把当前元素插入到前面已经有序的区间中。

```python
def insert_sort(nums):
    for i in range(1, len(nums)):
        current = nums[i]
        j = i - 1
        while j >= 0 and nums[j] > current:
            nums[j + 1] = nums[j]
            j -= 1
        nums[j + 1] = current
    return nums
```

## 8.4 快速排序

核心思想：选一个基准值，把小于它的放左边，大于它的放右边，再递归处理两边。

```python
def quick_sort(nums):
    if len(nums) <= 1:
        return nums

    pivot = nums[0]
    left = [x for x in nums[1:] if x <= pivot]
    right = [x for x in nums[1:] if x > pivot]
    return quick_sort(left) + [pivot] + quick_sort(right)
```

## 9. 二分查找

二分查找要求数据必须有序。

### 9.1 递归写法

```python
def binary_search(nums, target, left, right):
    if left > right:
        return False

    mid = (left + right) // 2
    if nums[mid] == target:
        return True
    if nums[mid] > target:
        return binary_search(nums, target, left, mid - 1)
    return binary_search(nums, target, mid + 1, right)
```

### 9.2 非递归写法

```python
def binary_search_loop(nums, target):
    left = 0
    right = len(nums) - 1

    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return True
        if nums[mid] > target:
            right = mid - 1
        else:
            left = mid + 1
    return False
```

二分查找的时间复杂度通常是 `O(log n)`。

## 10. 树与二叉树

树是一种典型的非线性结构。

常见概念：

- 根节点
- 父节点
- 子节点
- 叶子节点
- 子树

二叉树的特点：

- 每个节点最多有两个子节点
- 通常分为左子树和右子树

在笔记中还提到了用代码模拟二叉树，以及广度优先、深度优先遍历，这些是后续继续深入树结构的基础。

## 11. 稳定性

排序算法稳定性指的是：如果两个元素值相等，排序后它们的相对位置是否保持不变。

例如：

- 冒泡排序通常是稳定的
- 选择排序通常是不稳定的

## 12. 小结

- 数据结构解决“怎么存”
- 算法解决“怎么做”
- 分析算法时重点看时间复杂度
- 顺序表适合随机访问，链表适合频繁插删
- 排序和查找是算法入门核心
- 树是后续学习高级数据结构的重要基础
