# 学生管理系统与拷贝

## 学习目标

- 理解面向对象项目如何拆分模块
- 会设计学生类和管理类
- 掌握基础的增删改查思路
- 理解对象转字典、保存和加载
- 区分浅拷贝和深拷贝

## 1. 项目拆分思路

在课堂案例里，学生管理系统被拆成多个文件：

- `main.py`：程序入口
- `student.py`：学生类
- `studentcms.py`：学生管理类
- `student.txt`：持久化存储学生数据

这样做的好处：

- 结构清晰
- 便于维护
- 便于多人协作
- 代码职责更单一

## 2. 学生类设计

学生对象通常包含：

- 姓名
- 年龄
- 性别
- 手机号
- 备注

```python
class Student:
    def __init__(self, name, age, gender, mobile, desc):
        self.name = name
        self.age = age
        self.gender = gender
        self.mobile = mobile
        self.desc = desc

    def __str__(self):
        return (
            f"姓名：{self.name}，年龄：{self.age}，"
            f"性别：{self.gender}，手机号：{self.mobile}，备注：{self.desc}"
        )
```

## 3. 管理类设计

管理类负责维护一个学生列表，并提供操作方法。

```python
class StudentCMS:
    def __init__(self):
        self.students = []

    def add_student(self, student):
        self.students.append(student)

    def show_all(self):
        for student in self.students:
            print(student)
```

一个完整的管理系统一般会包含：

- 添加学生
- 删除学生
- 修改学生
- 查询单个学生
- 显示所有学生
- 保存到文件
- 从文件加载

## 4. 程序入口

主入口文件通常只做一件事：启动程序。

```python
from studentcms import StudentCMS


if __name__ == "__main__":
    cms = StudentCMS()
    cms.start()
```

这样可以避免导入模块时顺带执行测试代码。

## 5. 增删改查核心思路

### 5.1 添加

收集用户输入，创建 `Student` 对象，再放入列表。

```python
def add_student(self):
    stu = Student("张三", 18, "男", "13800000000", "新生")
    self.students.append(stu)
```

### 5.2 查询

根据姓名或手机号遍历列表并查找。

```python
def search_student(self, name):
    for stu in self.students:
        if stu.name == name:
            return stu
    return None
```

### 5.3 修改

先找到对象，再更新对象属性。

```python
def update_student(self, name, new_mobile):
    stu = self.search_student(name)
    if stu:
        stu.mobile = new_mobile
```

### 5.4 删除

找到目标对象后，从列表中移除。

```python
def delete_student(self, name):
    stu = self.search_student(name)
    if stu:
        self.students.remove(stu)
```

## 6. 对象转字典

对象保存到文件时，常常需要先转为字典。

Python 对象有一个常见属性 `__dict__`，可以拿到对象的实例属性。

```python
stu = Student("李四", 20, "男", "13900000000", "班长")
print(stu.__dict__)
```

输出结果类似：

```python
{
    "name": "李四",
    "age": 20,
    "gender": "男",
    "mobile": "13900000000",
    "desc": "班长"
}
```

如果有多个学生对象，就可以把它们整理成“列表嵌套字典”的结构。

```python
data = [stu.__dict__ for stu in self.students]
```

## 7. 保存与加载

### 7.1 保存

实际开发中更推荐保存为 JSON。

```python
import json


def save_student(self, path):
    data = [stu.__dict__ for stu in self.students]
    with open(path, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
```

### 7.2 加载

读取文件后，再把字典恢复成对象。

```python
def load_student(self, path):
    with open(path, "r", encoding="utf-8") as f:
        data = json.load(f)

    self.students = [Student(**item) for item in data]
```

## 8. 普通赋值、浅拷贝、深拷贝

### 8.1 普通赋值

普通赋值不会复制对象本身，只是新增一个引用。

```python
list1 = [1, 2, 3]
list2 = list1
list2[0] = 100
print(list1)  # [100, 2, 3]
```

### 8.2 浅拷贝

浅拷贝只复制第一层对象，内部嵌套的可变对象仍然共享。

```python
import copy

data1 = [1, 2, [3, 4]]
data2 = copy.copy(data1)
data2[2][0] = 999

print(data1)  # [1, 2, [999, 4]]
print(data2)  # [1, 2, [999, 4]]
```

### 8.3 深拷贝

深拷贝会递归复制内部嵌套对象。

```python
import copy

data1 = [1, 2, [3, 4]]
data2 = copy.deepcopy(data1)
data2[2][0] = 999

print(data1)  # [1, 2, [3, 4]]
print(data2)  # [1, 2, [999, 4]]
```

## 9. 如何判断用哪种拷贝

- 只想新增一个别名：普通赋值
- 结构简单，只需复制最外层：浅拷贝
- 存在多层嵌套，且希望完全独立：深拷贝

## 10. 小结

- 项目开发中要先做模块拆分
- 学生类负责“数据”，管理类负责“行为”
- 持久化时常用对象转字典
- 普通赋值不是复制
- 浅拷贝只复制第一层
- 深拷贝适合彻底隔离数据
