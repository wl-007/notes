# 面向对象

## 学习目标

- 理解面向对象和面向过程的区别
- 掌握类、对象、属性、方法、`self`
- 会使用常见魔法方法
- 掌握继承、封装、多态
- 理解类属性、类方法、静态方法

## 1. 面向对象是什么

面向过程关注的是“步骤”，面向对象关注的是“对象”。

例如“把大象装进冰箱”：

- 面向过程：开门、装进去、关门
- 面向对象：冰箱对象负责开门和关门，大象对象是被操作的对象

面向对象的三个核心特性：

- 封装：把数据和行为放到类中，对外提供接口
- 继承：子类复用父类的属性和方法
- 多态：同一个接口，在不同对象上表现不同

## 2. 类和对象

类是对一类事物的抽象，对象是类的具体实例。

```python
class Car:
    def run(self):
        print("汽车正在行驶")


car = Car()
car.run()
```

### 2.1 `self` 是什么

`self` 表示当前对象本身。调用 `car.run()` 时，Python 会自动把 `car` 传给 `self`。

```python
class Dog:
    def bark(self):
        print("对象自己在叫：", self)


dog = Dog()
dog.bark()
```

## 3. 属性和方法

对象一般有两类信息：

- 属性：描述对象是什么
- 方法：描述对象能做什么

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"我叫{self.name}，今年{self.age}岁")


stu = Student("小明", 18)
stu.introduce()
```

## 4. 常见魔法方法

### 4.1 `__init__`

对象创建后自动执行，常用于初始化属性。

```python
class Person:
    def __init__(self, name):
        self.name = name
```

### 4.2 `__str__`

打印对象时，返回更友好的字符串。

```python
class Book:
    def __init__(self, title, price):
        self.title = title
        self.price = price

    def __str__(self):
        return f"书名：{self.title}，价格：{self.price}"


book = Book("Python 入门", 59)
print(book)
```

### 4.3 `__del__`

对象被销毁时可能触发，但实际开发里不建议依赖它做关键资源管理。

```python
class Demo:
    def __del__(self):
        print("对象被销毁了")
```

## 5. 继承

继承可以提高代码复用率。

```python
class Animal:
    def eat(self):
        print("正在吃东西")


class Dog(Animal):
    def bark(self):
        print("汪汪叫")


dog = Dog()
dog.eat()
dog.bark()
```

### 5.1 单继承

一个子类只有一个父类。

```python
class Father:
    def walk(self):
        print("会走路")


class Son(Father):
    pass
```

### 5.2 多继承

一个子类同时继承多个父类。

```python
class Master:
    def make_cake(self):
        print("传统做法")


class School:
    def make_cake(self):
        print("学校做法")


class Student(Master, School):
    pass
```

当多个父类有同名方法时，Python 会按 MRO 顺序查找。

```python
print(Student.__mro__)
```

### 5.3 重写和 `super()`

子类可以重写父类同名方法，也可以通过 `super()` 调用父类实现。

```python
class Animal:
    def speak(self):
        print("动物发声")


class Cat(Animal):
    def speak(self):
        super().speak()
        print("喵喵叫")


cat = Cat()
cat.speak()
```

## 6. 封装

封装的核心是“隐藏实现细节，对外暴露必要接口”。

Python 没有真正强制的私有属性，但可以用双下划线做约定式私有。

```python
class BankCard:
    def __init__(self, password):
        self.__password = password

    def check_password(self, pwd):
        return self.__password == pwd


card = BankCard("123456")
print(card.check_password("123456"))
```

## 7. 多态

多态强调“同一套调用方式，作用于不同对象时有不同表现”。

```python
class Dog:
    def make_noise(self):
        print("汪汪汪")


class Cat:
    def make_noise(self):
        print("喵喵喵")


def play(animal):
    animal.make_noise()


play(Dog())
play(Cat())
```

多态的关键不是父子关系本身，而是对象是否提供了同样的方法接口。

## 8. 类属性、类方法、静态方法

### 8.1 类属性

类属性属于类本身，所有对象共享。

```python
class Person:
    count = 0

    def __init__(self):
        Person.count += 1


p1 = Person()
p2 = Person()
print(Person.count)
```

### 8.2 类方法

类方法通过 `@classmethod` 定义，第一个参数通常写 `cls`。

```python
class Dog:
    count = 0

    def __init__(self):
        Dog.count += 1

    @classmethod
    def show_count(cls):
        print("对象总数：", cls.count)
```

### 8.3 静态方法

静态方法通过 `@staticmethod` 定义，不依赖类属性和对象属性，更像是“放在类里的普通工具函数”。

```python
class MathTool:
    @staticmethod
    def add(a, b):
        return a + b


print(MathTool.add(10, 20))
```

## 9. 小结

- 类是模板，对象是实例
- `self` 代表当前对象
- `__init__` 负责初始化，`__str__` 负责友好输出
- 继承解决复用，`super()` 解决调用父类实现
- 封装强调隐藏细节
- 多态强调统一接口
- 类属性、类方法、静态方法分别对应不同场景
