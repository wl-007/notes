#### 变量的定义

在程序中，有时我们需要对2个数据进行求和，那么该怎样做呢？类比一下现实生活中，比如去超市买东西，往往需要一个菜篮子，用来进行存储物品，等到所有的物品都购买完成后，再到收银台进行结账即可. 如果在程序中，需要把2个数据，或者多个数据进行求和的话，那么就需要把这些数据先存储起来，然后把它们累加起来可. Python中，存储一个数据，需要一个叫做变量的东西...

```python
num1 = 100 #num1就是一个变量，就好一个小菜篮子

num2 = 87  #num2也是一个变量

result = num1 + num2 #把num1和num2这两个"菜篮子"中的数据进行累加，然后放到 result变量中
```

说明:

- 所谓变量，可以理解为菜篮子. 买菜需要把菜放到菜篮子里, 那么程序中的数据就需要放到变量里.
- 程序就是用来处理数据的，而变量就是用来存储数据的

#### 算术运算符

下面以a=10 ,b=20为例进行计算

- 运算符 | 描述 | 实例
- + | 加 | 两个对象相加 a + b 输出结果 30
- - | 减 | 得到负数或是一个数减去另一个数 a - b 输出结果 -10

```python
>>> 10 + 5.5 * 2
21.0
>>> 10 + (5.5 * 2)
21.0
```

#### 什么是字符串

字符串是由一串字符组成的数据, 在 Python 中使用引号包裹起来的内容就是字符串。字符串可以保存姓名、地址、说明文本、文件路径等文字信息。

#### 字符串的定义

Python 中可以使用单引号、双引号或三引号定义字符串。

```python
name = "Alice"
city = 'Shanghai'
message = """这是多行字符串。
可以保存多行文本。"""

print(name)
print(city)
print(message)
```

说明:

- 单引号和双引号都可以定义普通字符串。
- 三引号可以定义多行字符串, 适合保存较长的文本内容。
- 如果字符串内容本身包含单引号, 外层可以使用双引号; 如果内容本身包含双引号, 外层可以使用单引号。

#### 字符串拼接

字符串可以使用 `+` 进行拼接, 拼接后会生成一个新的字符串。

```python
first_name = "张"
last_name = "三"
full_name = first_name + last_name

print(full_name)          # 张三
print("你好，" + full_name) # 你好，张三
```

注意: `+` 两边必须都是字符串。如果要把数字拼接到字符串中, 需要先使用 `str()` 转换, 或使用格式化输出。

#### 重复字符串

字符串可以使用 `*` 重复多次。

```python
print("ha" * 3)  # hahaha
print("-" * 30)
```

常见用途:

- 输出分隔线。
- 快速生成重复内容。

#### 获取字符串长度

使用 `len()` 可以获取字符串中字符的个数。

```python
text = "Python"
print(len(text))  # 6
```

#### 字符串是不可变类型

字符串创建后, 不能直接修改某个位置的字符。

```python
word = "hello"

# 错误写法: 字符串不支持按下标直接修改
# word[0] = "H"

# 正确写法: 生成一个新的字符串
new_word = "H" + word[1:]
print(new_word)  # Hello

word = word.replace("h", "a")
print(word)  # aello
```

说明: 字符串的 `replace()`、拼接、切片等操作都不会在原字符串上直接修改, 而是生成新的字符串结果。

#### 转义字符

有些字符不能直接写在字符串中, 或者直接写出来含义不清楚, 可以使用反斜杠 `\` 进行转义。

```python
print("第一行\n第二行")   # \n 表示换行
print("姓名\t年龄")       # \t 表示制表符
print("他说：\"你好\"")    # \" 表示双引号
```

常见转义字符:

- `\n`: 换行
- `\t`: 制表符
- `\"`: 双引号
- `\'`: 单引号
- `\\`: 一个普通反斜杠

#### 原始字符串

在字符串前面加 `r`, 可以让反斜杠不再作为转义字符, 常用于 Windows 路径或正则表达式。

```python
path = r"C:\Users\name\Desktop"

```

### 3.3 字符串--下标和切片

#### 学习目标

- 掌握字符串下标的使用
- 掌握切片语法
- 能够使用切片获取字符串中的一部分内容

#### 下标

字符串中的每个字符都有自己的位置, 这个位置叫做下标, 也叫索引。

Python 中下标从 `0` 开始:

```python
text = "Python"

print(text[0])   # P
print(text[1])   # y
print(text[-1])  # n
```

说明:

- 正数下标从左往右数, 第一个字符的下标是 `0`。
- 负数下标从右往左数, 最后一个字符的下标是 `-1`。
- 如果下标超出范围, 程序会报错。

#### 切片

切片用于从字符串中取出一部分内容。

语法:

```python
字符串[开始:结束:步长]
```

说明:

- `开始`: 从哪个下标开始取, 包含该位置。
- `结束`: 取到哪个下标之前, 不包含该位置。
- `步长`: 每次移动的间隔, 默认是 `1`。

示例:

```python
text = "Python"

print(text[0:2])   # Py
print(text[2:])    # thon
print(text[:4])    # Pyth
print(text[::2])   # Pto
print(text[::-1])  # nohtyP
print(text[1:5:2]) # yh
```

切片常用写法:

- `text[0:2]`: 从下标 `0` 取到下标 `2` 之前。
- `text[2:]`: 从下标 `2` 取到最后。
- `text[:4]`: 从开头取到下标 `4` 之前。
- `text[::2]`: 从头到尾每隔一个字符取一次。
- `text[::-1]`: 字符串反转。

### 4.10 函数的多种参数

#### 学习目标

- 掌握不定长参数

#### 位置参数

位置参数：调用函数时根据函数定义的参数位置来传递参数。

```python
def user_info(name, age, gender):
    print(f'您的名字是{name}, 年龄是{age}, 性别是{gender}')

user_info('TOM', 20, '男')
```

注意：传递和定义参数的顺序及个数必须一致。

#### 关键字参数

函数调用，通过“键=值”形式加以指定。可以让函数更加清晰、容易使用，同时也清除了参数的顺序需求。

```python
def user_info(name, age, gender):
    print(f'您的名字是{name}, 年龄是{age}, 性别是{gender}')

user_info('Rose', age=20, gender='女')
user_info('小明', gender='男', age=16)
```

注意：函数调用时，如果有位置参数时，位置参数必须在关键字参数的前面，但关键字参数之间不存在先后顺序。

#### 缺省参数

缺省参数也叫默认参数，用于定义函数，为参数提供默认值，调用函数时可不传该默认参数的值（注意：所有位置参数必须出现在默认参数前，包括函数定义和调用）。

```python
def user_info(name, age, gender='男'):
    print(f'您的名字是{name}, 年龄是{age}, 性别是{gender}')

user_info('TOM', 20)
user_info('Rose', 18, '女')
```

注意：函数调用时，如果为缺省参数传值则修改默认参数值；否则使用这个默认值。

#### 不定长参数

不定长参数也叫可变参数。用于不确定调用的时候会传递多少个参数(不传参也可以)的场景。此时，可用包裹(packing)位置参数，或者包裹关键字参数，来进行参数传递，会显得非常方便。

- 包裹位置传递
```python
def user_info(*args):
    print(args)
```

- 数据文件，例如 `.json`

文件操作的核心目的:

- r+ | 打开一个文件用于读写。文件指针将会放在文件的开头。
- rb+ | 以二进制格式打开一个文件用于读写。文件指针将会放在文件的开头。
- w | 打开一个文件只用于写入。如果该文件已存在则打开文件，并从开头开始编辑，即原有内容会被删除。如果该文件不存在，创建新文件。

#### 了解异常

例如：以r方式打开一个不存在的文件。

#### 异常的写法

#### 语法

```python

    可能发生错误的代码

```

#### 快速体验

#### 体验


#### 捕获多个指定异常

```python
try:
    print(num)
```

```python

```

```python
try:

    print(result)
else:
    print('我是else，是没有异常的时候执行的代码')
```

finally表示的是无论是否异常都要执行的代码，例如关闭文件。

```python
try:

else:
```

#### 异常的传递

体验异常传递

需求：

```python
import time
try:
    f = open('test.txt')
    try:
        while True:
            content = f.readline()
            if len(content) == 0:
                break
            time.sleep(2)
            print(content)
    except:
        # 如果在读取文件的过程中，产生了异常，那么就会捕获到
        # 比如 按下了 ctrl+c
        print('意外终止了读取数据')
...
```

说明:

- 如果当前代码块没有处理异常，异常会继续向上层传递。
- 谁调用了这个函数，谁就有机会继续捕获这个异常。
- 这也是为什么很多函数内部不一定直接处理异常，而是把异常交给调用者决定怎么处理。

#### 抛出异常

除了捕获异常，我们也可以在程序中主动抛出异常，这时需要使用 `raise` 关键字。

语法:

```python
raise 异常类型('异常说明')
```

示例:

```python
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为 0")
    return a / b


try:
    print(divide(10, 2))
    print(divide(10, 0))
except ValueError as error:
    print("捕获到异常：", error)
```

说明:

- `raise` 的作用是主动告诉程序：这里出现了不合法情况。
- `ValueError` 表示“值不合法”。
- 抛出异常后，后续代码不会继续执行，而是进入对应的 `except` 处理。

#### 为什么要主动抛出异常

有些错误并不是 Python 解释器自动发现的，而是业务规则不允许。

例如:

- 除数不能为 `0`
- 年龄不能小于 `0`
- 用户名不能为空
- 密码长度不能少于 6 位

这类情况就适合使用 `raise` 主动抛出异常，让调用者明确知道哪里出错了。

#### 自定义异常

如果内置异常类型不能准确表达业务含义，我们可以自己定义异常类。

自定义异常一般继承 `Exception`。

语法:

```python
class 自定义异常名(Exception):
    pass
```

示例:

```python
class AgeError(Exception):
    """年龄不合法时抛出的异常。"""


def check_age(age):
    if age < 0 or age > 120:
        raise AgeError("年龄必须在 0 到 120 之间")
    return f"年龄 {age} 合法"


try:
    print(check_age(18))
    print(check_age(150))
except AgeError as error:
    print("捕获到异常：", error)
```

说明:

- `AgeError` 是我们自己定义的异常类型。
- 当年龄超出范围时，程序主动抛出 `AgeError`。
- 调用方可以专门捕获这个异常，让错误信息更清晰。

#### 自定义异常的好处

- 让异常含义更明确
- 让业务错误和系统错误更容易区分
- 便于调用者按不同异常类型分别处理

#### 综合示例

下面的代码同时使用了 `try`、`except`、`else`、`finally`:

```python
samples = ["20", "abc", "0", "5"]

for text in samples:
    try:
        num = int(text)
        result = 100 / num
    except ValueError:
        print(f"{text} 不是数字")
    except ZeroDivisionError:
        print("除数不能为 0")
    else:
        print(f"100 / {num} = {result}")
    finally:
        print(f"本次处理结束：{text}")
```

运行逻辑:

- 如果字符串不能转为整数，进入 `ValueError`。
- 如果除数为 `0`，进入 `ZeroDivisionError`。
- 如果没有异常，执行 `else`。
- 不管有没有异常，都会执行 `finally`。

#### 制作模块

在Python中，每个Python文件都可以作为一个模块，模块的名字就是文件的名字。也就是说自定义模块名必须要符合标识符命名规则。

#### 定义模块

新建一个Python文件，命名为my_module1.py，并定义testA函数。

```python
def testA(a, b):
    print(a + b)
```

#### 测试模块

在实际开中，当一个开发人员编写完一个模块后，为了让模块能够在项目中达到想要的效果，这个开发人员会自行在py文件中添加一些测试信息.，例如，在my_module1.py文件中添加测试代码。

```python
def testA(a, b):
    print(a + b)

testA(1, 1)
```

此时，无论是当前文件，还是其他已经导入了该模块的文件，在运行的时候都会自动执行testA函数的调用。

#### 调用模块

```python
import my_module1

```

#### 注意事项

如果使用from .. import ..或from .. import *导入多个模块的时候，且模块内有同名功能。当调用这个同名功能的时候，调用到的是后面导入的模块的功能。

- 体验
```python
# 模块1代码

from my_module2 import my_test

# my_test函数是模块2中的函数

```

#### 包

包将有联系的模块组织在一起，即放到同一个文件夹下，并且在这个文件夹创建一个名字为__init__.py 文件，那么这个文件夹就称之为包。

#### 为什么要使用包

当项目变大后，如果所有代码都放在一个目录下，会越来越难管理。包的作用就是把一组有关联的模块整理到同一个目录中，便于分类、复用和维护。

例如:

- 把和用户相关的模块放到 `user` 包里
- 把和订单相关的模块放到 `order` 包里
- 把工具函数放到 `utils` 包里

可以把包理解成“模块的文件夹”。

#### 制作包

[New] — [Python Package] — 输入包名 — [OK] — 新建功能模块(有联系的模块)。

注意：新建包后，包内部会自动创建__init__.py文件，这个文件控制着包的导入行为。

#### 包的目录结构

下面是一个最简单的包结构:

```python
my_package/
    __init__.py
    my_module1.py
    my_module2.py
```

说明:

- `my_package` 是包名。
- `__init__.py` 表示这个目录是一个 Python 包。
- `my_module1.py`、`my_module2.py` 是包中的模块。

#### __init__.py 的作用

`__init__.py` 是包的初始化文件，主要有几个常见作用:

- 标记当前目录是一个包
- 控制 `from 包名 import *` 时允许导入哪些模块
- 编写包级别的初始化代码

例如:

```python
__all__ = ["my_module1", "my_module2"]
```

这表示当使用 `from my_package import *` 时，只导入这两个模块。

#### 快速体验

- 新建包mypackage
- 新建包内模块：my_module1 和 my_module2
- 模块内代码如下
```python
# my_module1
print(1)

def info_print1():
    print('my_module1')
```

再准备另一个模块:

```python
# my_module2
def info_print2():
    print('my_module2')
```

包的 `__init__.py` 可以这样写:

```python
__all__ = ["my_module1", "my_module2"]
```

#### 导入包

#### 方法一

```python
import 包名.模块名

包名.模块名.目标
```

这是最常见、最清晰的写法。

#### 体验

```python
import my_package.my_module1

my_package.my_module1.info_print1()
```

如果还要使用第二个模块，也可以继续这样导入:

```python
import my_package.my_module2

my_package.my_module2.info_print2()
```

#### 方法二

注意：必须在__init__.py文件中添加__all__ = []，控制允许导入的模块列表。

```python
from 包名 import *
模块名.目标
```

这种写法依赖 `__init__.py` 中的 `__all__` 配置。

#### 体验

```python
from my_package import *

my_module1.info_print1()
my_module2.info_print2()
```

#### 推荐写法

实际开发中，更推荐下面两种写法:

```python
import my_package.my_module1
```

或:

```python
from my_package import my_module1
```

原因:

- 代码来源更清楚
- 不容易和别的变量、函数重名
- 比 `from 包名 import *` 更容易维护

#### 包和模块的区别

- 模块: 一个 `.py` 文件就是一个模块。
- 包: 一个包含 `__init__.py` 的文件夹就是一个包。

例如:

- `模块1.py` 是模块
- `my_package` 是包
- `my_package/my_module1.py` 是包中的模块

假设目录如下:

```python

    __init__.py
    my_module1.py
    my_module2.py
main.py
```
