## 阅读建议

- 先把 `001` 看熟，再进入单个算法
- 每学一个算法，都先回答它解决什么问题、输入输出是什么、常见优缺点是什么
- 代码部分尽量自己手敲一遍，不要只看
- KNN、逻辑回归、SVM 这类算法，最好顺手练一下标准化
- 聚类和降维建议结合可视化一起看
