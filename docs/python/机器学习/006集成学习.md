# 006 集成学习

## 集成学习是什么

集成学习的核心思想是：

不要只依赖一个模型，而是组合多个模型，让整体效果更稳、更强。

## 两大主流方向

### Bagging

代表模型：

- 随机森林

思路：

- 并行训练多个基模型
- 最后投票或平均

### Boosting

代表模型：

- AdaBoost
- GBDT
- XGBoost

思路：

- 后一个模型重点学习前一个模型没学好的地方
- 串行提升整体效果

## 随机森林

随机森林本质上是多棵决策树的组合。

它通常比单棵决策树更稳，泛化能力更强。

### 优点

- 稳定
- 不容易像单棵树那样严重过拟合
- 在表格数据任务中很常用

## AdaBoost

AdaBoost 会不断提升前面分错样本的权重，让后续模型更关注难样本。

## GBDT

GBDT 是梯度提升树，属于经典的 Boosting 方法，在传统机器学习里非常重要。

## XGBoost

XGBoost 是工程上很强的树模型提升方案，常用于：

- 比赛
- 风控
- 排序
- 表格数据建模

## 集成学习的优点

- 泛化能力通常比单模型更好
- 对复杂任务更有表现力
- 在结构化数据场景非常强

## 集成学习的代价

- 训练和解释成本更高
- 模型更复杂
- 调参空间更大

## 本章小结

学集成学习时，先把框架记住：

- 决策树是基础
- 随机森林属于 Bagging
- AdaBoost / GBDT / XGBoost 属于 Boosting
- 表格数据任务里，集成学习经常是主力方法
