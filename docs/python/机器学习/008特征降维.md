# 008 特征降维

## 什么是特征降维

特征降维就是把高维数据压缩到更低维，同时尽量保留主要信息。

## 为什么需要降维

常见原因：

- 特征太多，训练成本高
- 特征之间存在冗余
- 数据中有噪声
- 想做二维或三维可视化

## PCA 是什么

PCA 是课程里最常见的降维方法。

它会寻找数据中“变化最明显”的方向，把原始数据投影到这些方向上。

## PCA 的作用

- 压缩特征
- 去噪
- 提升训练效率
- 辅助可视化

## PCA 的代价

降维后通常会损失一部分信息，而且新特征往往失去原始业务含义，可解释性会下降。

## 什么时候适合试降维

当你遇到这些情况时，可以考虑降维：

- 特征维度过高
- 模型训练太慢
- 多个特征明显高度相关
- 想把高维数据投影到二维平面观察结构

## 本章小结

这一篇要掌握的重点是：

- 降维不是随便删特征
- PCA 更像是“重新构造更少的新特征”
- 它适合压缩、去噪和可视化
