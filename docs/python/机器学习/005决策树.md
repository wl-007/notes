# 005 决策树

## 决策树是什么

决策树是一种通过不断“提问”和“切分数据”来完成预测的模型。

你可以把它理解成一连串条件判断：

- 如果年龄小于某值
- 并且收入高于某值
- 那么更可能属于某一类

## 决策树能做什么

- 分类
- 回归

## 核心思想

从根节点开始，选择一个最合适的特征进行划分，让数据被一步步分成更纯的子集，直到满足停止条件。

## 常见划分指标

- 信息增益
- 信息增益率
- 基尼指数

不同树算法使用的划分标准可能不同。

## 决策树的优缺点

### 优点

- 很直观
- 可解释性强
- 能处理非线性关系
- 对数据预处理要求相对低

### 缺点

- 容易过拟合
- 单棵树稳定性较差

## 如何缓解过拟合

常见方法包括：

- 限制树深度
- 限制叶子节点最少样本数
- 做剪枝

## 决策树适合什么场景

如果你希望：

- 模型比较容易解释
- 快速建立一个可读规则系统
- 对特征之间的非线性关系建模

决策树是很常见的起点。

## 本章小结

学习决策树时，要重点抓住：

- 它的本质是不断划分数据
- 它可解释性强
- 它容易过拟合
- 它也是很多集成学习模型的基础
