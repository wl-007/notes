## 查询参数

```python
@DeptRouter.get("/items")
async def read_item(skip: int = 0, limit: int = 10):
    return fake_items_db[skip : skip + limit]
```

## 路径参数

```python
@DeptRouter.get(
    "/detail/{dept_id}",
    summary="根据查询部门详情",
)
async def get_dept_detail(dept_id: int):
    return {"message": "dept detail", "id": dept_id}

```

RESTful风格的查询建议使用，但是匹配优先级较高（按接口定义从上往下匹配），一般加一个前缀，比如`detail`，假设是这样，那么`/me`的逻辑便永远不会触发：

```py

@DeptRouter.get(
    "/{dept_id}",
    summary="根据查询部门详情",
)
async def get_dept_detail(dept_id: int):
    return {"message": "dept detail", "id": dept_id}

@DeptRouter.get("/me")
async def read_user_me():
    return {"id": "the current user"}

```


## 简单实体对象

1. 导入 Pydantic 的 BaseModel。
2. 然后，把数据模型声明为继承 BaseModel 的类。
3. 使用 Python 标准类型声明所有属性。

```python
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None

@DeptRouter.post("/items")
async def create_item(item: Item):
    return {
        "name": item.name,
        "price": item.price
    }
```
测试

```shell
  curl -X POST "http://127.0.0.1:8801/apiCommon/test/dept/items" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "元气基站",
    "price": 998
  }'
```

## get的参数也可以使用简单实体定义

在一个 Pydantic 模型中声明你需要的查询参数，然后将参数声明为 Query：

```py
from typing import Annotated, Literal

from fastapi import FastAPI, Query
from pydantic import BaseModel, Field

app = FastAPI()


class FilterParams(BaseModel):
    limit: int = Field(100, gt=0, le=100)
    offset: int = Field(0, ge=0)
    order_by: Literal["created_at", "updated_at"] = "created_at"
    tags: list[str] = []


@app.get("/items/")
async def read_items(filter_query: Annotated[FilterParams, Query()]):
    return filter_query
```

## Pydantic

所有数据校验都由 [Pydantic](https://pydantic.dev/docs/validation/latest/get-started/) 在幕后完成。Pydantic 是 Python 中使用最广泛的数据验证库。

## typing.Annotated

Annotated 是 Python 3.9+（typing 模块，3.9 起可用）引入的一个类型工具，用来给类型附加额外的元数据（metadata），而不改变类型本身的含义。

## 查询参数的校验

- 导入 Query 和 Annotated¶

```py
from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(q: Annotated[str | None, Query(max_length=50)] = None):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results
```

- 默认值: `= None` 表示默认值为`None`，也可以是 `= 'update'` 表示默认值为`update`。 等于`None`时，参数会变成可选参数。
- Annotated：第一个参数是类型，第二个参数是元数据。用Query装饰器来校验查询参数。

```shell
Query(
    default=Undefined,
    *,
    default_factory=_Unset,
    alias=None,
    alias_priority=_Unset,
    validation_alias=None,
    serialization_alias=None,
    title=None,
    description=None,
    gt=None,
    ge=None,
    lt=None,
    le=None,
    min_length=None,

    regex=None,
    discriminator=None,
    strict=_Unset,
    multiple_of=_Unset,
    allow_inf_nan=_Unset,
    max_digits=_Unset,

    example=_Unset,

```
[Query](https://fastapi.tiangolo.com/zh/reference/parameters/?h=Query#fastapi.Query)

需要关注一下 `alias`与`pattern`。

- `alias`：参数别名，默认为参数名。
- `pattern`：正则匹配，如果匹配失败，则返回400错误。

```py
@app.get("/items/")
async def read_items(dept_name: Annotated[str | None, Query(alias="name")] = None):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if dept_name:
        results.update({"dept_name": dept_name})
    return results
```

## 路径参数的校验

使用Annotated与Path

```py
@DeptRouter.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(title="The ID of the item to get")],
    name: Annotated[str | None, Query(alias="dept-name")] = None,
):
    results = {"item_id": item_id}
    if name:
        results.update({"q": name})
    return results
```

## 请求体的校验

使用Annotated与Body。

::: tip
校验字段直接从 pydantic 导入 Field。
Field 第一个参数是字段的默认值，后面参数是字段的校验规则。
:::

```py
from typing import Annotated

from fastapi import Body, FastAPI
from pydantic import BaseModel, Field

class FilterParams(BaseModel):
    limit: int = Field(10, gt=0, le=100)
    offset: int = Field(0, ge=0)
    order_by: Literal["created_at", "updated_at"] = "created_at"
    tags: list[str] = []


@DeptRouter.get("/items/")
async def read_items(filter_query: Annotated[FilterParams, Query()]):
    return filter_query
```

## 日期参数

### 优先用 ISO 8601 字符串

ISO 8601 是国际标准化组织（ISO）的标准，也是 REST/JSON API 里时间表示的事实标准。

```text
2026-09-30T10:00:00        # 本地时间（无时区，有歧义）
2026-09-30T10:00:00+08:00  # 带时区偏移
2026-09-30T02:00:00Z       # UTC（Z = +00:00）
```
为什么它是主流：

- JSON 本身没有「时间」类型，只有 string / number，所以时间必须是字符串或数字。

- ISO 8601 可读、带时区、跨语言通用。

- FastAPI / Pydantic、Spring / Jackson、Go、.NET 等框架默认都用它。

- OpenAPI 规范里，format: date-time 明确指向 RFC 3339（ISO 8601 的一个子集）。

```yaml
# OpenAPI 里的定义
type: string
format: date-time   # 期望 RFC 3339 / ISO 8601

```
RFC 3339 是 ISO 8601 的「互联网专用子集」，强制要求带时区：

```text
2026-09-30T10:00:00+08:00   ✅
2026-09-30T10:00:00Z        ✅
2026-09-30T10:00:00         ❌ 没有时区，RFC 3339 不合法
```

定义方式，使用`datetime.datetime`类型：

```py
class alarmQuery(BaseModel):
    name: str
    start_time: datetime.datetime
    end_time: datetime.datetime


@DeptRouter.put("/items176")
async def query_item(item: alarmQuery):
    results = {"item": item}
    return results
```

测试：

```shell
  curl -X POST "http://127.0.0.1:8801/apiCommon/test/dept/items176" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "alarm1",
      "start_time": "2026-09-30T10:00:00+08:00",
    "end_time": "2026-09-30T12:00:00+08:00"
  }'
```

### 时间戳（Unix Timestamp

Unix 时间戳 = 从 1970-01-01 00:00:00 UTC 起的秒数（或毫秒数）。

优点：

- 无时区歧义（本质是 UTC）

- 紧凑、易于计算和排序

- 适合机器间通信、数据库存储、日志

缺点：

- 不可读，人看不懂 1790179200 是哪天

- 单位不统一：秒（10 位）vs 毫秒（13 位），极易出错

- 丢失时区语义（虽然本质 UTC，但展示时要选时区）

定义方式，使用`datetime.datetime`类型加转换函数：

```py
# ① 定义东八区时区对象
CST = datetime.timezone(datetime.timedelta(hours=8))

class alarmQuery181(BaseModel):
    name: str
    start_time: datetime.datetime
    end_time: datetime.datetime

    @field_validator("start_time", "end_time", mode="before")
    @classmethod
    def ts_to_datetime(cls, v):
        if isinstance(v, (int, float)):
            return datetime.datetime.fromtimestamp(v, tz=CST)
        return v

@DeptRouter.put("/items187")
async def query_item187(item: alarmQuery181):
    results = {"item": item}
    return results
```

  -H "Content-Type: application/json" \
  -d '{
    "name": "alarm1",
      "start_time": 1790179200,
    "end_time": 1790783999
  }'
