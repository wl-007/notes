# FastAPI 入门示例

对应提交：`785a8f6`（2026-09-23，入门示例）。

下面的应用可以在两个地址接收 GET 请求：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def read_root():
    return {"Hello": "World"}


@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):
    return {"item_id": item_id, "q": q}
```

把代码保存为独立练习项目的 `main.py`，然后启动：

```bash
uv init fastapi-demo
cd fastapi-demo
uv add "fastapi[standard]"
# 在此目录创建 main.py，内容使用上面的示例。
uv run fastapi dev main.py
```

```bash
curl "http://127.0.0.1:8000/items/5?q=somequery"
```

```json
{"item_id": 5, "q": "somequery"}
```

这是独立示例的默认端口。当前模板项目通过 Typer 启动，默认端口是 `8801`，见下一篇。

## FastAPI 做了哪些事

`@app.get()` 将 Python 函数注册成路径操作。函数签名既参与编辑器提示，也参与运行时校验和 OpenAPI 文档生成。

| 声明 | 在请求中的含义 |
| --- | --- |
| `"/items/{item_id}"` | 路径占位符 |
| `item_id: int` | 解析路径内容并转换为整数 |
| `q: str \| None = None` | 可省略的查询参数 |
| 返回 `dict` | 默认转换为 JSON 响应 |

请求 `/items/abc` 时，`item_id` 无法解析为整数，默认返回 HTTP 422。不要把类型提示理解为只有编辑器会检查。

FastAPI 主要结合两类能力：Starlette 提供 ASGI、路由和中间件等基础设施，Pydantic 负责数据模型、校验与序列化。OpenAPI 描述接口结构，Swagger UI 用于交互调试。

## FastAPI、Uvicorn 和 ASGI 的关系

```text
浏览器 / curl → Uvicorn → ASGI 接口 → FastAPI 应用 → 路由函数
```

- FastAPI 决定接口行为。
- Uvicorn 是运行应用的 ASGI 服务器。
- ASGI 约定服务器与应用怎样交换连接信息、请求与响应消息，也支持 WebSocket 和生命周期事件。

因此，安装 FastAPI 不等于已经启动服务；也不需要自己实现底层 HTTP 协议。

## 同步函数和异步函数如何选择

有可以 `await` 的异步 I/O 时，使用 `async def`，例如项目中的异步 MySQL 和 Redis 调用：

```python
@app.get("/health")
async def health():
    return {"status": "ok"}
```

普通 `def` 路由会由框架在线程池中执行。`async def` 本身不会把同步阻塞代码变成异步；在其中直接执行耗时同步调用，会占住事件循环。CPU 密集工作应考虑线程、进程或任务系统，结合任务性质选择。

当前系统用户模块将 bcrypt 运算交给 `run_in_threadpool()`，数据库请求则使用异步驱动。这两种处理解决的问题不同。

## 交互式文档

默认地址：

| 地址 | 用途 |
| --- | --- |
| `/docs` | Swagger UI |
| `/redoc` | ReDoc |
| `/openapi.json` | 接口描述文件 |

文档页面本身可以访问，不代表每个业务接口都允许匿名调用。后续的 JWT 和 Swagger 章节会解释这一点。

## 使用现有模板

```bash
cd /path/to/fastapi_template/backend
uv sync --locked
uv run main.py run --env=dev
```

Node 只用于可选的 npm/pnpm 脚本或前端开发，不是运行 Python 后端的必要条件。uv 管理 Python 环境与依赖，`uv.lock` 固定解析结果；不要在复现已有仓库时用一串 `uv add` 重新选择依赖版本。
