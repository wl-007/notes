## 先认识完整请求链路

```text
客户端请求
  → Uvicorn：接收 HTTP 请求并调用 ASGI 应用
  → 中间件：例如处理 CORS
  → 路由匹配：API_PREFIX + 模块前缀 + 接口路径
  → 参数校验与依赖注入：Pydantic、DbSession、CurrentUser、RedisDep
  → Controller：收参、调用业务、组织响应
  → Service：业务校验、权限、缓存策略
  → CRUD / RedisCURD：访问 MySQL 或 Redis
  → response_model：过滤和序列化返回值
  → 客户端接收响应
```

数据库会话由带 `yield` 的依赖管理。当前使用默认 request scope，退出事务的时机另见数据库章节，不能把上图理解为“提交一定早于响应发送”。

## 本地复现前的准备

```bash
cd /path/to/fastapi_template/backend
uv sync --locked
uv run main.py --help
uv run main.py run --env=dev
```

项目要求 Python `>=3.13`。库版本以 `backend/uv.lock` 为准，不把某个安装工具版本当作 FastAPI 的要求。

- 配置文件放在 `backend/env/.env.dev` 或 `.env.prod`，启动命令先选择环境再导入配置。
- MySQL 需要自行启动并准备表结构；当前仓库没有 Compose 配置，也没有启动时执行 `create_all()` 的逻辑。
- Alembic 已接入，但当前默认禁用，`versions` 没有已提交的迁移脚本，见迁移章节。
- 登录需要配置至少 32 字节的 `JWT_SECRET_KEY`。
- Redis 可选；不可用时热门用户回源 MySQL，但这不代表 MySQL 也可以省略。

学习技术原理时，可以独立运行文中的最小示例；调用项目接口时，使用上述真实地址与前置条件。
