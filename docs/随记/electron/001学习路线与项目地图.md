# Electron 实战：从一个窗口到常驻桌面工具箱

这套笔记用 jyt-pocket 的真实实现，解释一个前端页面怎样变成桌面应用，再怎样变成“快捷键呼出、点外面收起、只在菜单栏留图标”的常驻工具。

例如，点击其他应用后自动收起，最小实现只有这几行：

```ts
// 主进程：window 是 BrowserWindow 实例，不是浏览器的 window。
window.on('blur', () => {
  window.hide()
})
```

但实际项目还需要处理文件选择框引起的失焦、窗口置顶、快速切回、退出清理。这些不是另一套神秘技术，而是在 Electron 事件上补齐状态判断。后面的教程会从最小代码逐步走到项目实现。

## 这套教程怎样使用

源码基准是 2026-11-18 本地 jyt-pocket 工作区，包括当时尚未提交的常驻窗口改造。后续项目改动可能使行号变化，因此主要通过文件名和函数名定位。

示例有三种标记：

- **独立练习**：可以在练习工程中替换对应入口运行。
- **项目节选**：抽取真实实现中的关键代码，依赖上下文里已有的变量或函数。
- **建议配置**：用于后续完善，不代表项目已经设置。

不要把所有代码块依次粘贴到同一个文件。不同步骤可能是在演示同一功能的基础版和完善版；同名函数应替换，不要重复注册事件。

前端部分只解释与 Electron 的连接：调用 preload、订阅消息、拖动区域、键盘事件、状态同步。React 组件样式、卡片布局、shadcn 表单实现不在这里展开。

## 先掌握这条调用链

```text
用户点击“执行”
  → React 调用 window.api.selectDirectory(commandId)
  → preload 调用 ipcRenderer.invoke
  → 主进程 ipcMain.handle 接收
  → 主进程读取已保存命令，校验执行资格
  → dialog.showOpenDialog 选择目录
  → 页面展示命令和目标目录，用户确认
  → 页面只提交 commandId 和 cwd
  → 主进程重新校验，child_process.spawn 启动程序
  → stdout / stderr 持续输出
  → webContents.send 推送日志
  → preload 转交业务事件
  → React 展示日志
```

这条链里，页面负责交互，preload 负责暴露有限接口，主进程负责系统能力和校验。后面所有功能都可以放回这个结构里理解。

## 本项目已实现什么

当前应用启动时创建窗口但不直接显示，保留托盘入口。用户可以通过托盘或 `CommandOrControl+Shift+Space` 呼出窗口，再次按快捷键收起；点击其他应用也会收起。窗口置顶时暂停自动收起，原生文件对话框打开期间也暂停。

“和 uTools 类似”在这里指这些可观察到的交互，不代表我们知道 uTools 内部使用了完全相同的代码。

图标方面，已增加终端形状的托盘图标和网页 favicon；`build/icon.icns`、`build/icon.ico`、`build/icon.png` 等正式应用图标仍是模板资源。第 4 篇会逐项解释如何替换，避免误以为改了托盘图标就已经改完应用图标。

## 学完以后可以自己解释的 API

| 需求 | 核心 API |
| --- | --- |
| 等 Electron 准备好 | `app.whenReady()` |
| 创建原生窗口 | `new BrowserWindow(options)` |
| 加载页面 | `loadURL()` / `loadFile()` |
| 显示、聚焦、隐藏 | `show()` / `focus()` / `hide()` |
| 判断窗口状态 | `isVisible()` / `isMinimized()` / `isFocused()` |
| 关闭前拦截 | `window.on('close', ...)` |
| 点击外面自动收起 | `window.on('blur', ...)` |
| 不占 Windows 任务栏 | `skipTaskbar` |
| 隐藏 macOS Dock | `app.dock.hide()`，打包配合 `LSUIElement` |
| 菜单栏或系统托盘图标 | `new Tray(image)` |
| 托盘菜单 | `Menu.buildFromTemplate()` |
| 全局快捷键 | `globalShortcut.register()` |
| 页面请求主进程 | `ipcRenderer.invoke()` + `ipcMain.handle()` |
| 主进程推送消息 | `webContents.send()` + `ipcRenderer.on()` |
| 暴露页面 API | `contextBridge.exposeInMainWorld()` |
| 选文件、选目录、选保存路径 | `dialog.showOpenDialog()` / `showSaveDialog()` |
| 启动外部程序 | Node.js `child_process.spawn()` |
| 获取用户数据目录 | `app.getPath('userData')` |
| 读写数据 | Node.js `fs/promises` |
| 窗口置顶 | `setAlwaysOnTop()` |
| 图片转 Electron 原生图像对象 | `nativeImage.createFromPath()` |
