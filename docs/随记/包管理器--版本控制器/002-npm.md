# npm 发布自己的包

创建账号： https://www.npmjs.com/，控制台登录npm , 后就可以发布自己的包了

```js
--登录 npm  
npm login

--发布包
npm publish
```

# 常用命令

```bash
初始化项目  npm init -y
查看源      npm config get registry

npm config set registry http://npm0.yinhaiyun.com/
设置为官网  npm config set registry https://registry.npmjs.org/
设置淘宝源  npm config set registry https://registry.npm.taobao.org
取消证书验证 npm config set strict-ssl false

下载 npm install jquery@3.5.1 --save-dev 
卸载 npm uninstall jquery    
```



## 查看依赖包版本

```
# 查看某个 package 的注册信息
npm view <package-name>

# 查看某个 package 的最新版本
npm view <package-name> version

# 查看某个 package 在 npm 服务器上所发布过的版本
npm view <package-name> versions

# 查看仓库依赖树上所有包的版本信息
npm ls
```

## 配置npm的全局模块的存放路径、cache的路径

```
npm config set prefix "选择刚刚创建node_global文件路径"
npm config set cache "选择刚刚创建node_cache文件路径"
```
