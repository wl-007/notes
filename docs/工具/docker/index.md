# Docker

## 这部分讲什么

这里整理的是 Docker 的实用入门和进阶工作流，不追求把所有命令背全，而是先把日常开发最常用的路径讲清楚。

目前分成两篇：

- [入门](./入门.md)：先理解镜像、容器、Dockerfile、卷、网络和最常用命令
- [进阶](./进阶.md)：继续往 Compose、多阶段构建、开发工作流和排障思路走

## 建议阅读顺序

1. 先看 [入门](./入门.md)，把“镜像和容器到底是什么”吃透
2. 自己跑一遍 `docker run`、`docker build`
3. 再看 [进阶](./进阶.md)，理解多容器和项目化管理
