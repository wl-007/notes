# 数据库

> 对个人开发者来说，数据库不是“会连上就行”，而是要能设计数据、写对查询、控制性能、保证数据安全。

## 你需要掌握什么

### 1. 关系型数据库基础

- 表、行、列的概念
- 主键、外键、唯一约束、非空约束
- 一对一、一对多、多对多的建模方式
- 范式的基本思想，不必死记，但要理解“避免冗余和异常更新”

至少要能做到：

- 为用户、订单、文章、评论、订阅等业务设计基础表结构

### 2. SQL 能力

- `select`、`insert`、`update`、`delete`
- `where`、`order by`、`group by`
- 聚合函数：`count`、`sum`、`avg`、`max`、`min`
- `join` 的使用
- 子查询和分页

至少要熟练：

- 写出满足业务需求的查询
- 避免把所有数据查出来再在代码里过滤

### 3. 索引

- 索引的作用和代价
- B+ 树索引的基本思想
- 什么字段适合建索引
- 联合索引和最左匹配
- 为什么索引多了也会影响写入

至少要理解：

- 为什么一个查询突然变慢
- 为什么加了索引后仍然没有生效

### 4. 事务

- 事务的基本概念
- ACID 是什么
- 提交、回滚
- 脏读、不可重复读、幻读
- 隔离级别的大致区别

至少要会用在：

- 扣库存
- 支付状态更新
- 多表写入一致性

### 5. 锁与并发

- 行锁、表锁
- 乐观锁、悲观锁
- 死锁的基本原因
- 高并发更新同一条数据时会发生什么

至少要理解：

- 为什么接口有时会卡住
- 为什么明明 SQL 很简单却执行很慢

### 6. 执行计划与性能优化

- `explain` 的基本看法
- 全表扫描是什么
- 回表、覆盖索引基本概念
- 慢查询日志的用途
- SQL 优化不是只靠“加索引”

至少要能优化：

- 列表分页查询
- 条件筛选查询
- 联表查询
- 统计类查询

### 7. 数据安全与恢复

- 备份和恢复的基本流程
- 误删数据怎么办
- 迁移脚本如何管理
- 生产环境改表为什么要谨慎

至少要有意识：

- 任何重要数据都要能备份
- 任何结构变更都要可回滚或可补救

### 8. 缓存与数据库边界

- 什么适合放数据库，什么适合放缓存
- Redis 不能替代关系型数据库
- 缓存穿透、击穿、雪崩了解概念即可

至少要理解：

- 为什么热点数据不能全靠数据库硬扛
- 为什么缓存和数据库会有一致性问题

## 作为前端转全栈的学习重点

### 第一阶段

- 先把 MySQL 或 PostgreSQL 用熟一个
- 能自己设计表结构
- 能独立写增删改查和常见联表 SQL

### 第二阶段

- 掌握索引、事务、锁、执行计划
- 能对慢 SQL 做基础优化

### 第三阶段

- 学会备份恢复、迁移管理、读写分离、缓存协同

## 推荐的实战场景

- 用户系统：注册、登录、会话、权限
- 内容系统：文章、标签、评论、分类
- 订单系统：下单、支付状态、库存扣减
- 订阅系统：会员、账单、回调记录
- 数据后台：搜索、筛选、分页、统计报表

## 判断自己是否掌握

- 你能从业务需求出发表结构
- 你能写出正确且可维护的 SQL
- 你能解释索引为什么生效或失效
- 你能处理并发更新和事务一致性问题
- 你能对常见慢查询做出有效优化
