# Linux

> 对个人开发者来说，Linux 的目标很明确：你要能把服务部署上去，并且出了问题能自己查。

## 你需要掌握什么

### 1. 目录结构和文件操作

- 常见目录作用：`/home`、`/etc`、`/var`、`/usr`、`/tmp`
- 当前目录、绝对路径、相对路径
- 创建、复制、移动、删除文件和目录
- 查看文件内容：`cat`、`less`、`tail`
- 搜索文件：`find`、`rg`

至少要熟练：

- 找到配置文件、日志文件、项目目录
- 看日志、改配置、备份文件

### 2. 权限管理

- `rwx` 权限含义
- `chmod`、`chown`、`chgrp`
- 用户与用户组
- `sudo` 的使用场景

至少要理解：

- 为什么文件能看不能改
- 为什么服务能启动但读不到某个目录

### 3. 进程管理

- `ps`、`top`、`htop`
- `kill`、`kill -9`
- 后台运行：`nohup`、`&`
- 端口与进程关系：`lsof`、`ss`、`netstat`

至少要能做到：

- 找到某个服务是否在运行
- 查出哪个进程占了端口
- 杀掉异常进程并重新启动服务

### 4. 日志与排障

- `tail -f` 实时看日志
- `grep` / `rg` 搜索错误信息
- 查看系统日志和服务日志
- 区分应用报错、权限报错、网络报错、磁盘报错

至少要养成习惯：

- 出问题先看日志，不凭感觉改代码

### 5. 网络相关

- IP、端口、域名、DNS 的关系
- `curl` 测试接口
- `ping`、`traceroute` 基本用途
- 防火墙、安全组、监听地址的概念

至少要会排查：

- 服务启动了但外部访问不到
- 域名解析正常但接口超时
- 本机能访问，公网不能访问

### 6. 包管理和环境管理

- `apt`、`yum` 的基本使用
- 软件安装、升级、卸载
- Node.js、Python、数据库等运行环境安装
- 环境变量配置：`PATH`、`NODE_ENV` 等

至少要能完成：

- 配置一台新机器的基础开发和运行环境

### 7. Shell 基础

- 常见命令组合使用
- 重定向：`>`、`>>`
- 管道：`|`
- 通配符和变量
- 简单 Bash 脚本

至少要能写：

- 启动脚本
- 部署脚本
- 备份脚本

### 8. 服务部署基础

- Nginx 基本反向代理
- `systemd` 服务管理
- 进程守护和开机启动
- HTTPS 证书续期的基本流程
- Docker 常见命令和容器排查

至少要会做：

- 部署前端静态站点
- 部署 Node.js API 服务
- 反向代理域名到服务端口

## 作为前端转全栈的学习重点

### 优先级最高

- 文件操作
- 日志查看
- 进程管理
- 端口排查
- 网络联通性检查
- Nginx 基础配置

### 第二优先级

- Shell 脚本
- `systemd`
- Docker
- 定时任务 `crontab`

### 第三优先级

- 更深入的系统调优
- 内核参数
- 复杂权限和安全策略

## 判断自己是否掌握

- 你能独立把一个前后端项目部署到 Linux 服务器
- 你能根据日志定位大多数启动失败问题
- 你能查出端口占用、权限不足、磁盘空间不足、域名或反向代理配置错误
- 你能写出简单可维护的部署脚本
