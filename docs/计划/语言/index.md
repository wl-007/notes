# 语言

> 对前端转全栈的个人开发者来说，语言学习不在“多”，而在“能覆盖真实场景”。

## 第一优先级

### Python

- 如果你想先补一门对个人开发最实用的语言，Python 比 Go 更适合作为第一选择
- 对数据分析、自动化脚本、爬虫、AI 调用、批处理工具都很方便
- 学习曲线相对平缓，容易尽快进入“能做东西”的状态
- 对前端开发者来说，也更适合作为 Node.js 之外的第二语言

[查看 Python 学习方向](./Python.md)

### JavaScript / TypeScript

- 作为主力开发语言，需要继续加强
- 要能同时覆盖前端、Node.js 服务端、工程化脚本
- 重点掌握类型系统、异步模型、模块化、运行时差异

### SQL

- 虽然它不一定被单独当成“编程语言”，但它是数据库工作的核心语言
- 要能独立完成查询、更新、聚合、联表、索引优化

## 第二优先级

### Bash

- 用于服务器操作、部署脚本、自动化任务
- 不要求写复杂脚本，但要能读、改、排查

### Go

- Go 更适合高性能 API、并发服务、CLI 工具
- 如果后面你确定会长期做服务端，可以再补 Go

## 选择建议

- 如果你当前想先补最容易见效的一项，先学 Python
- 如果你当前最想提升的是数据处理能力、自动化能力、AI 工具整合能力，优先 Python
- 如果你以后主要精力放在高性能后端服务，再补 Go
- 不管选哪条路线，TypeScript、SQL、Bash 都仍然要持续补齐
