# Python

> 对前端转全栈的个人开发者来说，Python 最适合作为“先补起来就能马上用”的第二语言。

## 为什么先学 Python

- 语法简单，能更快进入实战
- 很适合写自动化脚本和小工具
- 数据分析生态成熟，`NumPy`、`Pandas`、`Matplotlib` 都很常用
- 接 AI 服务、做数据处理、跑离线任务都很方便
- 以后不管你做内容产品、SaaS、爬虫、数据报表还是 AI 应用，Python 都很有用

- 做简单的数据探索和可视化

## 学什么最有用

### 第一阶段

- 基础语法
- 函数
- 常用数据结构
- 文件操作
- 异常处理
- 模块和包

### 第二阶段

- `NumPy`
- `Pandas`
- 数据清洗
- 分组统计
- 时间处理
- 数据可视化

### 第三阶段

- 网络请求
- 并发基础
- 脚本工程化
- 简单 Web 框架
- AI API 集成

## 对你当前最实用的学习顺序

1. Python 基础
2. `Pandas` 数据处理
3. `Matplotlib` 可视化
4. 自动化脚本
5. API 调用和 AI 集成

## 判断是否值得先投入

如果你最近有这些需求，就应该先补 Python：

- 需要处理数据表
- 想做自动化脚本
- 想做 AI 相关工具
- 想快速补一门实用性很强的语言
