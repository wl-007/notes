# 计划

> 面向前端转全栈、并以个人开发者为目标的学习计划。

## 学习目标

- 能独立完成产品开发、部署、运维和排障
- 不只会写页面，也能处理服务端、数据库和线上环境问题
- 学的内容以“够用、能落地、能长期复用”为主

## 学习原则

- 优先补齐直接影响开发和上线能力的知识
- 先掌握常用部分，再逐步深入底层原理
- 每个主题都要落实到“会查、会配、会用、会排查”
