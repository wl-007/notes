网络编程与并发 ​

学习目标 ​

  • 理解网络编程三要素
  • 掌握 TCP 基本通信流程
  • 理解多进程和多线程的区别
  • 掌握线程资源共享与互斥锁
  • 理解 with open() 背后的上下文管理器

1. 网络编程基础 ​

网络编程的目标是让不同计算机上的程序进行数据交互。

三要素：

  • IP 地址：设备在网络中的地址
  • 端口号：程序在设备中的标识
  • 协议：通信双方遵守的规则

1.1 TCP 和 UDP ​

TCP：

  • 面向连接
  • 基于字节流
  • 可靠
  • 速度相对较慢

UDP：

  • 无连接
  • 基于数据报
  • 不保证可靠
  • 速度相对较快

2. socket 入门 ​

socket 是网络编程的核心对象。

python
import socket

cli_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
print(cli_socket)

参数含义：

  • AF_INET：使用 IPv4
  • SOCK_STREAM：使用 TCP 字节流

3. TCP 通信流程 ​

3.1 服务器端 ​

python
import socket


server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server_socket.bind(("127.0.0.1", 5555))
server_socket.listen(5)

conn, addr = server_socket.accept()
conn.send("欢迎学习 socket".encode("utf-8"))
data = conn.recv(1024)
print(data.decode("utf-8"))

conn.close()
server_socket.close()

3.2 客户端 ​

python
import socket


client_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
client_socket.connect(("127.0.0.1", 5555))

data = client_socket.recv(1024)
print(data.decode("utf-8"))

client_socket.send("收到消息".encode("utf-8"))
client_socket.close()

3.3 通信步骤总结 ​

服务器端通常遵循下面顺序：

  1. 创建 socket 对象
  2. 绑定 IP 和端口
  3. 设置监听
  4. 等待客户端连接
  5. 收发数据
  6. 关闭连接

客户端通常遵循下面顺序：

  1. 创建 socket 对象
  2. 连接服务器
  3. 收发数据
  4. 关闭连接

4. 多进程 ​

进程可以理解为“正在运行的程序实例”。

4.1 基本用法 ​

python
import multiprocessing
import time


def coding(name, count):
    for i in range(count):
        print(f"{name} 正在敲第 {i} 遍代码")
        time.sleep(0.1)


if __name__ == "__main__":
    p = multiprocessing.Process(target=coding, args=("张三", 3))
    p.start()

4.2 进程参数 ​

  • target：目标函数
  • args：元组形式传参
  • kwargs：字典形式传参
  • name：进程名称

4.3 获取进程 ID ​

python
import os
import multiprocessing


print(os.getpid())
print(multiprocessing.current_process().pid)

4.4 进程之间数据隔离 ​

不同进程默认不能直接共享普通全局变量。

python
import multiprocessing

my_list = []


def write_data():
    my_list.append(1)
    print("子进程中的列表：", my_list)


if __name__ == "__main__":
    p = multiprocessing.Process(target=write_data)
    p.start()
    p.join()
    print("主进程中的列表：", my_list)

5. 多线程 ​

线程是进程内部的执行单元。一个进程中可以有多个线程。

5.1 基本用法 ​

python
import threading
import time


def music():
    for i in range(3):
        print("听音乐", i)
        time.sleep(0.1)


t = threading.Thread(target=music)
t.start()

5.2 线程共享资源 ​

线程之间默认共享同一进程的内存资源。

python
import threading

num = 0


def add():
    global num
    for _ in range(100000):
        num += 1

多个线程同时修改共享变量时，可能出现数据错乱。

6. 互斥锁 ​

互斥锁用于保护共享资源，避免多个线程同时修改同一份数据。

python
import threading

num = 0
lock = threading.Lock()


def add():
    global num
    for _ in range(100000):
        lock.acquire()
        num += 1
        lock.release()

更推荐使用更安全的写法：

python
with lock:
    num += 1

7. join() 和守护线程 ​

  • join()：让主线程等待子线程执行结束
  • 守护线程：主线程结束后，守护线程也会结束
python
t = threading.Thread(target=music, daemon=True)
t.start()
t.join()

8. 上下文管理器 ​

日常写文件时经常看到：

python
with open("demo.txt", "r", encoding="utf-8") as f:
    print(f.read())

它的好处是：

  • 代码更简洁
  • 自动释放资源
  • 异常时也能正确收尾

8.1 本质 ​

with 背后依赖的是上下文管理器协议：

  • __enter__()
  • __exit__()

8.2 自定义上下文管理器 ​

python
class MyFile:
    def __init__(self, path, mode, encoding="utf-8"):
        self.path = path
        self.mode = mode
        self.encoding = encoding
        self.file = None

    def __enter__(self):
        self.file = open(self.path, self.mode, encoding=self.encoding)
        return self.file

    def __exit__(self, exc_type, exc_val, exc_tb):
        if self.file:
            self.file.close()


with MyFile("demo.txt", "w") as f:
    f.write("hello")

9. 小结 ​

  • 网络编程核心对象是 socket
  • TCP 开发要分清客户端和服务器端流程
  • 多进程默认数据隔离
  • 多线程默认资源共享
  • 共享资源场景常需要互斥锁
  • with 的底层依赖上下文管理器协议
