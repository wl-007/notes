生成器与正则 ​

学习目标 ​

  • 理解生成器的作用
  • 掌握 yield 的基本用法
  • 学会分批生成数据
  • 掌握 property 的两种常见写法
  • 掌握正则表达式基础语法

1. 生成器 ​

生成器用于“按需生成数据”，不会一次性把所有结果全部放进内存。

适用场景：

  • 数据量较大
  • 只需要逐步取值
  • 希望节省内存

1.1 生成器表达式 ​

python
nums = (i for i in range(1, 6))
print(nums)
print(next(nums))
print(next(nums))

和列表推导式对比：

python
list_data = [i for i in range(1, 6)]
gen_data = (i for i in range(1, 6))
  • 列表：一次性生成全部数据
  • 生成器：需要时再取

1.2 yield ​

只要函数里出现了 yield，这个函数调用后返回的就是生成器对象。

python
def get_numbers():
    for i in range(1, 6):
        yield i


gen = get_numbers()
print(next(gen))
print(next(gen))

也可以配合 for 遍历：

python
for item in get_numbers():
    print(item)

2. 批量生成数据 ​

课堂笔记里有一个典型场景：按批次读取文件内容。

python
import math


def dataset_loader(data_lines, batch_size):
    batch_count = math.ceil(len(data_lines) / batch_size)
    for i in range(batch_count):
        start = i * batch_size
        end = start + batch_size
        yield data_lines[start:end]


data = list(range(1, 21))
for batch in dataset_loader(data, 6):
    print(batch)

这个思路非常适合：

  • 分页读取
  • 批量训练数据
  • 大文件分段处理

3. property ​

property 可以把“方法调用”包装成“属性访问”。

3.1 装饰器写法 ​

python
class Student:
    def __init__(self):
        self.__name = "张三"

    @property
    def name(self):
        return self.__name

    @name.setter
    def name(self, value):
        self.__name = value


stu = Student()
print(stu.name)
stu.name = "李四"
print(stu.name)

3.2 函数式写法 ​

python
class Student:
    def __init__(self):
        self.__age = 18

    def get_age(self):
        return self.__age

    def set_age(self, value):
        self.__age = value

    age = property(get_age, set_age)

适用场景：

  • 需要在读取属性时做封装
  • 需要在赋值时做校验

4. 正则表达式简介 ​

正则表达式用于字符串匹配、校验、提取、替换。

Python 中常用 re 模块。

python
import re

5. match()、search()、compile() ​

5.1 match() ​

从字符串开头开始匹配。

python
import re

result = re.match(r"\d+", "123abc")
print(result.group())

5.2 search() ​

在整个字符串中查找第一个匹配项。

python
result = re.search(r"it", "hello it world")
print(result.group())

5.3 compile() ​

先编译规则，再重复使用。

python
pattern = re.compile(r"\d+")
print(pattern.findall("a12b34c56"))

6. 常见元字符 ​

6.1 单字符匹配 ​

  • .：任意单个字符，默认不匹配换行
  • \d：数字
  • \D：非数字
  • \s：空白字符
  • \S：非空白字符
  • \w：字母、数字、下划线、汉字
  • \W：非 \w
  • [abc]：a、b、c 中任意一个
  • [^abc]：除 a、b、c 外任意一个
python
print(re.match(r"\d", "8abc"))
print(re.match(r"[abc]", "b123"))

6.2 数量词 ​

  • ?：0 次或 1 次
  • *：0 次或多次
  • +：1 次或多次
  • {n}：恰好 n 次
  • {n,}：至少 n 次
  • {n,m}：n 到 m 次
python
print(re.match(r"\d{3}", "123abc"))
print(re.match(r"\w{4,20}", "python_01"))

6.3 开头与结尾 ​

  • ^：开头
  • $：结尾
python
print(re.match(r"^\d{6}$", "123456"))

6.4 或者 ​

使用 | 表示“或者”。

python
print(re.match(r"^(163|126|qq)\.com$", "qq.com"))

7. 分组 ​

括号可以对表达式进行分组，也可以提取局部结果。

python
result = re.match(r"(qq):(\d+)", "qq:123456")
print(result.group(1))
print(result.group(2))

命名分组写法：

python
result = re.match(r"(?P<name>qq):(?P<number>\d+)", "qq:123456")
print(result.group("name"))
print(result.group("number"))

8. 正则应用示例 ​

8.1 邮箱校验 ​

python
pattern = r"^[A-Za-z0-9_]{4,20}@(163|126|qq)\.[A-Za-z]{2,3}$"
print(re.match(pattern, "python_01@qq.com"))

8.2 敏感词替换 ​

python
text = "我喜欢黄鹤楼，也喜欢中华"
result = re.sub(r"黄鹤楼|中华", "*", text)
print(result)

8.3 HTML 标签简单匹配 ​

python
html = "<html>hello</html>"
result = re.match(r"<(\w+)>\w+</\1>", html)
print(bool(result))

9. 小结 ​

  • 生成器适合按需取值
  • yield 会把函数变成生成器
  • property 让方法看起来像属性
  • 正则常用于校验、匹配、替换、提取
  • match() 偏向从开头匹配，search() 偏向全文搜索
