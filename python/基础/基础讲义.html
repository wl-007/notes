什么是注释 ​

注释：在程序代码中对程序代码进行解释说明的文字

作用：注释不是程序，不能被执行，只是对程序代码进行解释说明，让别人可以看懂程序代码的作用，能够大大增强程序的可读性

变量的定义 ​

在程序中，有时我们需要对2个数据进行求和，那么该怎样做呢？类比一下现实生活中，比如去超市买东西，往往需要一个菜篮子，用来进行存储物品，等到所有的物品都购买完成后，再到收银台进行结账即可. 如果在程序中，需要把2个数据，或者多个数据进行求和的话，那么就需要把这些数据先存储起来，然后把它们累加起来可. Python中，存储一个数据，需要一个叫做变量的东西...

python
num1 = 100 #num1就是一个变量，就好一个小菜篮子

num2 = 87  #num2也是一个变量

result = num1 + num2 #把num1和num2这两个"菜篮子"中的数据进行累加，然后放到 result变量中

说明:

  • 所谓变量，可以理解为菜篮子. 买菜需要把菜放到菜篮子里, 那么程序中的数据就需要放到变量里.
  • 程序就是用来处理数据的，而变量就是用来存储数据的

下标 ​

字符串中的每个字符都有自己的位置, 这个位置叫做下标, 也叫索引。

Python 中下标从 0 开始:

python

print(text[-1])  # n

说明:

  • 正数下标从左往右数, 第一个字符的下标是 0。
  • 负数下标从右往左数, 最后一个字符的下标是 -1。
  • 如果下标超出范围, 程序会报错。

切片 ​

切片用于从字符串中取出一部分内容。

语法:

python
字符串[开始:结束:步长]

说明:

  • 开始: 从哪个下标开始取, 包含该位置。
  • 结束: 取到哪个下标之前, 不包含该位置。
  • 步长: 每次移动的间隔, 默认是 1。

示例:

python
text = "Python"

print(text[0:2])   # Py
print(text[2:])    # thon
print(text[:4])    # Pyth
print(text[::2])   # Pto
print(text[::-1])  # nohtyP
print(text[1:5:2]) # yh

切片常用写法:

  • text[0:2]: 从下标 0 取到下标 2 之前。
  • text[2:]: 从下标 2 取到最后。
  • text[:4]: 从开头取到下标 4 之前。
  • text[::2]: 从头到尾每隔一个字符取一次。
  • text[::-1]: 字符串反转。

抛出异常 ​

除了捕获异常，我们也可以在程序中主动抛出异常，这时需要使用 raise 关键字。

语法:

python
raise 异常类型('异常说明')

示例:

python
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为 0")
    return a / b


try:
    print(divide(10, 2))
    print(divide(10, 0))
except ValueError as error:
    print("捕获到异常：", error)

说明:

  • raise 的作用是主动告诉程序：这里出现了不合法情况。
  • ValueError 表示“值不合法”。
  • 抛出异常后，后续代码不会继续执行，而是进入对应的 except 处理。

为什么要主动抛出异常 ​

有些错误并不是 Python 解释器自动发现的，而是业务规则不允许。

例如:

  • 除数不能为 0
  • 年龄不能小于 0
  • 用户名不能为空
  • 密码长度不能少于 6 位

这类情况就适合使用 raise 主动抛出异常，让调用者明确知道哪里出错了。

自定义异常 ​

如果内置异常类型不能准确表达业务含义，我们可以自己定义异常类。

自定义异常一般继承 Exception。

语法:

python
class 自定义异常名(Exception):
    pass

示例:

python
class AgeError(Exception):
    """年龄不合法时抛出的异常。"""


def check_age(age):
    if age < 0 or age > 120:
        raise AgeError("年龄必须在 0 到 120 之间")
    return f"年龄 {age} 合法"


try:
    print(check_age(18))
    print(check_age(150))
except AgeError as error:
    print("捕获到异常：", error)

说明:

  • AgeError 是我们自己定义的异常类型。
  • 当年龄超出范围时，程序主动抛出 AgeError。
  • 调用方可以专门捕获这个异常，让错误信息更清晰。

自定义异常的好处 ​

  • 让异常含义更明确
  • 让业务错误和系统错误更容易区分
  • 便于调用者按不同异常类型分别处理

    except ZeroDivisionError:
        print("除数不能为 0")
    else:
        print(f"100 / {num} = {result}")
    finally:
        print(f"本次处理结束：{text}")

运行逻辑:

  • 如果字符串不能转为整数，进入 ValueError。
  • 如果除数为 0，进入 ZeroDivisionError。
  • 如果没有异常，执行 else。
  • 不管有没有异常，都会执行 finally。

7.2 面向对象是什么 ​

面向过程关注的是“步骤”，面向对象关注的是“对象”。

例如“把大象装进冰箱”：

  • 面向过程：开门、装进去、关门
  • 面向对象：冰箱对象负责开门和关门，大象对象是被操作的对象

面向对象的三个核心特性：

  • 封装：把数据和行为放到类中，对外提供接口
  • 继承：子类复用父类的属性和方法
  • 多态：同一个接口，在不同对象上表现不同

7.3 类和对象 ​

类是对一类事物的抽象，对象是类的具体实例。

python

动态给对象添加属性不推荐 ​

封装的核心是“隐藏实现细节，对外暴露必要接口”。

7.8 多态 ​

多态强调“同一套调用方式，作用于不同对象时有不同表现”。

    animal.make_noise()


play(Dog())

多态的关键不是父子关系本身，而是对象是否提供了同样的方法接口。
